# Обробка тексту підручника з програмування (Haskell)

Програма читає текст підручника з файлу, розбирає його на абзаци, речення,
слова та розділові знаки й видаляє всі слова заданої довжини, які починаються
з приголосної літери (української або латинської).

Під час формування результату табуляції та послідовності пробілів завжди
замінюються одним пробілом. Порожні рядки зберігають межі абзаців.

## Структура проєкту

- `TextTypes.hs` — типи `Символ`, `Слово`, `РозділовийЗнак`, `Пропозиція`,
  `Абзац`, `Текст`, а також довідник голосних/приголосних.
- `TextParser.hs` — нормалізація пробілів, розбір тексту та зворотне
  формування рядка зі структури `Текст`.
- `TextProcessor.hs` — видалення слів заданої довжини, що починаються
  з приголосної.
- `Main.hs` — командний рядок, читання/запис файлів у UTF-8.
- `input.txt` — приклад тексту підручника (зі змішаними пробілами й табуляціями).

## Компіляція та запуск

```bash
ghc -O2 -o prog Main.hs
./prog input.txt 4 output.txt
```

Формат виклику:

```
prog <вхідний_файл> <довжина_слів> [<вихідний_файл>]
```

Якщо вказати лише шлях до файлу, програма запросить довжину слова з клавіатури.
Без вихідного файлу результат виводиться лише на екран.

## Приклад

Для `input.txt` і довжини `4` видаляються, зокрема, `Мова`, `мова`,
`цілі`, `його`, а слова, що починаються з голосної (`Її`, `елемента`,
`обов'язково`), зберігаються.

## Особливості реалізації

- Розділові знаки не видаляються разом зі словом — вони залишаються в реченні
  і прилягають до сусіднього слова без пробілу.
- Десяткові числа типу `3.14` не розбиваються на речення.
- Слова, що починаються з цифри або розділового знака, не видаляються.
