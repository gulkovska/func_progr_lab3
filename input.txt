Мова   Haskell — це функціональна мова програмування.
Її  основу  складають  чисті функції та незмінні значення.

	Функція  map застосовує задану функцію до кожного елемента списку.
Наприклад:	map (+1) [1,2,3] дає [2,3,4].

Тип   Int описує цілі числа; тип String описує рядки.
Змінна x зберігає результат обчислення, після цього код виводить його на екран.
Чи потрібно це знати? Так, обов'язково!
